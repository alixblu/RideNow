# 04 - Data (RDS PostgreSQL)

Stack `ridenow-<env>-04-data` from `iac/stacks/04-data.yaml`. Depends on `02-network` (exports `PrivateSubnetIds` and `DbSecurityGroupId`).

## What it creates

- Six PostgreSQL RDS instances, one per service (database-per-service): `user`, `driver`, `trip`, `payment`, `matching` and `notification`. `realtime-gateway` has no database.
- One shared KMS key (`alias/ridenow-<env>-rds`, rotation on) that encrypts the instances and their master secrets.
- One DB subnet group over the private subnets.
- Master passwords generated by RDS and stored in Secrets Manager (`ManageMasterUserPassword`). No password appears in the template or in these guides.
- Each instance is private (`PubliclyAccessible: false`), uses the database security group from `02-network`, and keeps a final snapshot when the stack deletes it (`DeletionPolicy: Snapshot`).

## Deploy

Dependencies: `02-network` must be `CREATE_COMPLETE` or `UPDATE_COMPLETE`.

### Configure

Print the parameter values this environment passes to the stack.

```bash
params 04-data
```

Expected for `prod`: `Environment=prod`, `DbInstanceClass=db.t4g.micro`, `DbAllocatedStorage=20`, `MultiAz=true`, `BackupRetentionDays=30`, `DeletionProtection=false`, `EngineVersion=17`. For `dev`, `MultiAz=false` and `BackupRetentionDays=1`.

`EngineVersion` is a major version only, so RDS picks the latest available minor. To change values for one run only, pass them as overrides:

```bash
cfn_deploy 04-data DbInstanceClass=db.t4g.small MultiAz=false
```

### Run

Deploy the stack with the shared helper. Six RDS instances take roughly 10 to 20 minutes, longer with `MultiAz=true`.

```bash
cfn_deploy 04-data
```

Expected last line: `Successfully created/updated stack - ridenow-prod-04-data`.

Show the stack status.

```bash
stack_status 04-data
```

Expected: `CREATE_COMPLETE` (or `UPDATE_COMPLETE` on a re-run).

### If it fails

List the failed events, newest first.

```bash
stack_failures 04-data
```

If the status is `ROLLBACK_COMPLETE`, follow the recovery steps in `README.md` before redeploying. If the failure names a missing import, deploy `02-network` first.

## Post-Deploy

No post-deploy configuration is needed for this stack.

The database secrets are wired into Kubernetes later, in `06-eks-cluster.md` (Database secrets). The security group rule that lets the cluster reach the databases is created by `07-eks-addons.md`.

## Verify

Check that all six instances are available and encrypted, and that none is public.

```bash
aws rds describe-db-instances \
  --query "DBInstances[?starts_with(DBInstanceIdentifier,'ridenow-$ENV-')].[DBInstanceIdentifier,DBInstanceStatus,StorageEncrypted,PubliclyAccessible,MultiAZ]" \
  --output table
```

Expected: six rows (`ridenow-<env>-user-db`, `-driver-db`, `-trip-db`, `-payment-db`, `-matching-db`, `-notification-db`), each with status `available`, `StorageEncrypted` `True` and `PubliclyAccessible` `False`.

Check that each instance has a managed master secret.

```bash
aws rds describe-db-instances \
  --query "DBInstances[?starts_with(DBInstanceIdentifier,'ridenow-$ENV-')].[DBInstanceIdentifier,MasterUserSecret.SecretArn,MasterUserSecret.SecretStatus]" \
  --output table
```

Expected: six rows, each with a Secrets Manager ARN and status `active`.

Read one export with the shared helper.

```bash
exp data-UserDbEndpoint
```

Expected: a host name like `ridenow-prod-user-db.<id>.ap-southeast-1.rds.amazonaws.com`.

Show all twelve outputs (an endpoint and a secret ARN for each of the six databases).

```bash
stack_outputs 04-data
```

Expected: twelve rows: `UserDbEndpoint`, `UserDbSecretArn`, `DriverDbEndpoint`, `DriverDbSecretArn`, `TripDbEndpoint`, `TripDbSecretArn`, `PaymentDbEndpoint`, `PaymentDbSecretArn`, `MatchingDbEndpoint`, `MatchingDbSecretArn`, `NotificationDbEndpoint`, `NotificationDbSecretArn`.

Confirm that a later guide can read an export by the name it imports.

```bash
exp data-UserDbEndpoint
```

Expected: the user database endpoint host name. Every output above is exported as `ridenow-<env>-data-<OutputKey>`, so the same lookup works for all twelve; an empty result means that export is missing.
